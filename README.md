# Project Planck question packages

**Preparing human-authored replacements?** Start with the [per-question authorship and replacement checklist](summit/AUTHOR_REWRITE_GUIDE.md). It links exact-text review sheets for all 26 tasks and identifies the 78 assistant-generated rubric criteria. Existing ZIPs remain the AI-assisted versions until replacements are supplied and packaged.

## Download and submit one question at a time

**[Open the individual ZIP download page](summit/DOWNLOADS.md)**

1. Select a question and click **Download ZIP**.
2. Import that ZIP into a compatible submission form. Each archive has `task.json` at its root and contains the question, answer, solution, and a three-criterion rubric totaling 10 points.
3. Inspect the imported form, confirm your assigned domain and text-only eligibility, and press Submit.

[Download all 26 packages together](https://github.com/fl0wstate/project-planck/raw/refs/heads/main/summit/packages/all-questions.zip). Extract this bundle first; upload the individual question ZIPs, not the bundle.

These packages are prepared for a workflow that **permits AI-assisted content**, as requested. Rubrics are AI-assisted and based on the existing solutions. They do not satisfy the human-authorship restriction in the archived Summit instructions. Local checks establish package completeness, not scientific correctness or platform acceptance.

Older versions and retired candidates remain available as separate packages; these are not 26 independently approved submissions. Review related versions before choosing which to submit.

See [migration and packaging documentation](summit/README.md) for provenance and validation commands. Original task Markdown files remain unchanged.
